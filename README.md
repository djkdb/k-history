# 한국사 레전드 마스터

> **"한국사를 외우는 것이 아니라 평생 기억하게 만든다."**

한국사능력검정시험 전용 **장기기억 강화 학습 시스템**.
노베이스도 시험장에서 자동으로 답이 떠오르게 만드는 것이 목표입니다.

핵심 개념 108개를 12개 시대로 나누어, 하나하나에 **다단계 요약 · 출제 포인트 · 스토리텔링 ·
현대 비유 · 두문자 암기 · 실수 방지 비교표 · 애니메이션 인포그래픽**을 붙였습니다.
여기에 **국사편찬위원회가 공개한 실제 기출 10회차(500문항)** 를 그대로 담아,
개념 학습부터 실전 모의고사까지 한 앱에서 끝냅니다.

학습한 개념은 에빙하우스 망각곡선에 따라 자동으로 복습 일정이 잡히고,
데이터에서 생성된 퀴즈와 기출 오답이 함께 복습 큐로 모입니다.

```bash
npm install
npm run dev      # http://localhost:3000
```

## 무엇이 다른가

**1. 실제 기출을 실제 시험처럼 풉니다**

69~78회 심화 10회차, 500문항. 시험지 이미지를 그대로 띄우고 80분 카운트다운,
5지선다 OMR, 자동 채점과 등급 판정까지 이어집니다. 정답과 배점은 공식 정답표에서
추출했고, 정답표에 실린 빈도표와 대조해 검증했습니다.

**2. 글로만 외우지 않습니다**

구조가 있는 정보는 그림으로 봅니다. 신분 구조는 피라미드로, 통치 기구는 조직도로,
사건의 인과는 화살표가 그려지는 흐름도로 나타납니다. 스크롤해서 화면에 들어오면
애니메이션이 재생되고, 우측 상단 버튼으로 다시 볼 수 있습니다.

**3. 아직 안 배운 내용은 묻지 않습니다**

퀴즈 유형을 두 부류로 나눕니다. OX·객관식·빈칸·왕·연도·사건 판별은 **정답 개념 하나만**
알면 풀리므로 오답 보기가 범위 밖이어도 안전합니다. 반면 순서 배열은 **보기 전부**를
알아야 풀리므로, 학습 완료한 개념 안에서만 출제하고 학습량이 3개 미만이면 아예 내지
않습니다. 전 개념 × 전 유형 시뮬레이션으로 범위 밖 출제 0건을 검증했습니다.

**4. 중요도에 근거가 있습니다**

`examFrequency`("최근 20회 중 출제된 횟수")에서 별점이 `gradeFromFrequency()`로
**파생**됩니다. 등급을 손으로 매기지 않으므로 데이터가 늘어도 기준이 흔들리지 않습니다.

| 등급 | 기준 | 라벨 | 개수 |
| --- | --- | --- | --- |
| ★★★★★ | 14회 이상 | 반드시 암기 | 11 (10%) |
| ★★★★☆ | 10~13회 | 매우 중요 | 26 (24%) |
| ★★★☆☆ | 7~9회 | 자주 출제 | 39 (36%) |
| ★★☆☆☆ | 3~6회 | 알아두기 | 27 (25%) |
| ★☆☆☆☆ | 2회 이하 | 참고 | 5 (5%) |

시대별 비중도 한능검 심화 실제 배점에 맞췄습니다 — 조선 17% · 고려 15% · 삼국 11% ·
근현대 40% · 가야 1%.

## 기출 모의고사

**69~78회 심화 10회차 · 500문항**이 들어 있습니다. 출처는 국사편찬위원회가 공개한
기출 자료이며, 각 회차 화면에 출처가 표시됩니다.

- 제한 시간 카운트다운(심화 80분), 0이 되면 자동 제출 · 10분 남으면 경고
- 5지선다 OMR 답안, 다시 볼 문항 깃발 표시
- 제출 확인(미응답 경고) → 자동 채점 → **한능검 등급 판정**
- 틀린 문항의 개념이 오답노트·망각곡선 복습 큐에 자동 반영
- 응시 기록 저장, 회차별 최고 점수 표시

### 두 가지 제공 방식

문제지 PDF에 텍스트 레이어가 있는지에 따라 갈립니다.

| 방식 | 회차 | 화면 |
| --- | --- | --- |
| **문항 분할형** | 70·71·72·75·76·77 | 문항을 하나씩 넘기며 풀이 |
| **쪽 이미지형** | 69·73·74·78 | 시험지를 넘겨 보며, **그 쪽의 문항 답안만** 아래에 표시 |

쪽 이미지형은 스캔 PDF라 자동 분할이 불가능한 회차입니다(픽셀 밀도 분석 32/50,
Tesseract OCR 11/50으로 둘 다 신뢰도 미달). 각 쪽의 첫 문항 번호를 직접 확인해
문항↔쪽 매핑을 만들었고, 답안지가 현재 쪽 문항만 보여줍니다.

### 검증

| 검사 | 범위 | 결과 |
| --- | --- | --- |
| 공식 빈도표 대조 | 7개 회차 | 답지번호별·배점별 분포 **완전 일치** |
| 독립 파서 교차 검증 | 500문항 | 좌표 기반 재파싱과 **500/500 일치** |
| 이미지 ↔ 번호 | 300문항 | 불일치 0건 |
| 쪽 매핑 | 4개 회차 | 연속성·전범위·쪽수 일치 |
| 채점·등급 | 10개 회차 | 만점/0점/부분점수 정확, 등급컷 정상 |

### 회차 추가하기

```bash
pip install pymupdf pillow
python3 scripts/import-exam.py <문제지.pdf> <회차> advanced --answer-pdf <정답표.pdf>
```

문제지에서 문항 이미지를, 정답표에서 정답·배점을 자동 추출해
`src/data/mock-exams/round-<회차>-advanced.ts` 를 만듭니다. 이 파일을
`src/data/mock-exams/index.ts` 의 `MOCK_EXAMS` 배열에 넣으면 앱에 나타납니다.

임포터는 문서 전체에서 `숫자.` 토큰의 x좌표를 모아 좌단·우단 기준선을 찾고,
그 선에서 시작하는 것만 문항 번호로 인정합니다(본문 중 숫자·머리말 제외).
텍스트 레이어가 없으면 자동으로 쪽 이미지 모드로 전환합니다.

정답표는 원문자형(`① ② ③`)과 숫자형을 모두 지원하며, 50문항·합계 100점으로 검증합니다.

## 기억 강화 시스템

개념 상세(`/event/[id]`)는 이 앱의 심장입니다. 하나의 개념을 8가지 경로로 기억에 밀어 넣습니다.

**레전드 요약** — 10초 / 30초 / 1분 / 시험 직전 요약을 탭으로 전환합니다.
시험장에서 떠올릴 순서(연도 → 왕 → 사건 → 키워드 → 함정)도 함께 보여줍니다.

**한눈에 보기** — 애니메이션 인포그래픽. 아래 6종 중 개념에 맞는 것이 붙습니다.

| 종류 | 쓰임 | 애니메이션 |
| --- | --- | --- |
| `timeline` | 연표, 제도 변천, 사건 순서 | 시간축이 그려지고 노드가 순차 등장 |
| `pyramid` | 신분 구조 등 위계 | 아래(다수)에서 위(소수)로 쌓임 |
| `orgchart` | 중앙 정치 기구, 행정 조직 | 연결선이 그려진 뒤 기구가 등장 |
| `compare` | 헷갈리는 두 개념 | 좌우에서 마주 보며 진입, 가운데 VS |
| `flow` | 인과 연쇄, 전개 과정 | 단계마다 화살표가 그려짐 |
| `stat` | 규모 수치 | 0에서 목표값까지 카운트업 |

핵심 개념 22개에 전용 인포그래픽 26종을 큐레이션했고(조선 신분 구조, 신문왕 통치 조직,
4대 사화 순서, 전시과 변천, 거란 3차 침입, 임진왜란 전개, 식민 통치 3단계, 6월 항쟁 등),
전용 자료가 없는 개념도 데이터에서 "시대 흐름 속 이 사건의 자리" 연표와
"가장 많이 헷갈리는 지점" 비교를 자동 생성합니다. **108개 전 개념이 최소 1개 이상**의
시각 자료를 갖습니다.

**기억 보조 6종** — 스토리텔링(인물을 드라마 캐릭터처럼) · 현대 비유 · 두문자 암기 ·
말장난 · 감정 연결 · 장면 상상.

**실수 방지** — 시험에서 헷갈리는 지점(`traps`)을 빨간 비교 카드로. 이 데이터는
사건 판별 퀴즈의 해설로도 재사용됩니다.

## 퀴즈 엔진

문제는 미리 작성된 것이 아니라 `HistoryEvent` 필드에서 **생성**됩니다.
데이터를 추가하면 문제도 함께 늘어납니다.

| 유형 | 문제 | 오답 보기 출처 |
| --- | --- | --- |
| `ox` | 요약문의 참·거짓 | 인접 개념의 왕/연도를 바꿔치기<br>(기간이 겹치면 거짓이 아니므로 제외) |
| `multiple` | 설명 보고 사건 고르기 | 같은 시대·인접 연도 개념 |
| `king` | 사건 당시의 집권자 | 인접 시기 왕들 |
| `year` | 사건 시기 | 연도가 가까운 사건들 |
| `blank` | 요약문 빈칸 | 인접 개념의 키워드 |
| `order` | 시간순 배열 | **학습 완료 범위 안에서만** |
| `event` | 옳은 설명 고르기 | 같은 시대 다른 사건의 요약문 |
| `negative` | **옳지 않은** 설명 고르기 | 참 3개는 이 사건의 사실, 거짓 1개는 다른 사건 |
| `source` | 사료 읽고 (가) 추론 | 사건명·왕명을 가린 지문 + 같은 시대 개념 |

### 난이도

실제 시험이 어려운 이유는 답이 어려워서가 아니라 **선택지가 서로 비슷해서**입니다.
그래서 난이도를 네 축으로 조절합니다 — 출제 유형, 오답을 얼마나 가까운 곳에서 뽑는가,
어느 중요도까지 다루는가, 지문이 얼마나 직접적인가.

| 난이도 | 유형 | 오답이 같은 시대인 비율 | 다루는 개념 |
| --- | --- | --- | --- |
| **기초** | OX·객관식·왕 맞추기 | 15% (다른 시대가 섞여 소거가 쉬움) | ★3 이상 (평균 ★4.5) |
| **실전** | + 연도·빈칸·사건 판별·순서 배열 | 100% | ★2 이상 (평균 ★4.5) |
| **고난도** | + 부정형·사료 제시형 | 100% (연도까지 인접) | ★1 이상 (평균 ★3.1) |

사료 제시형은 지문에서 사건명과 왕 이름을 `(가)`로 가립니다. 한국어 조사가 붙어
어간이 남는 경우(`고인돌과` → `고인돌`)까지 처리하며, 가린 자리가 너무 많아
읽기 힘들어지면 그 개념은 사료형을 만들지 않습니다. 사료형 161문항을 전수 검사해
정답 단서 노출 0건을 확인했습니다.

## 망각곡선 복습

학습을 완료하면 복습 카드가 생성되고, 아래 간격으로 자동 스케줄링됩니다.

```
당일 → 1일 → 3일 → 7일 → 14일 → 30일
```

정답이면 다음 단계로, 오답이면 한 단계 후퇴하고 12시간 뒤 재등장합니다.
대시보드의 **암기율**은 각 카드의 기억 보존율 `R = exp(-경과일 / 안정도)`을
평균 낸 추정치입니다(안정도 = 현재 단계 간격 + 1).

퀴즈 오답과 **기출 모의고사 오답**이 같은 복습 큐로 모입니다.

## 기술 스택

| 영역 | 선택 |
| --- | --- |
| 프레임워크 | Next.js 15 (App Router, 정적 익스포트) · React 19 · TypeScript |
| 스타일 | TailwindCSS v4 · 다크 테마 고정 · 시대별 전용 컬러 |
| 애니메이션 | **Motion**(framer-motion) — 화면 전환·단일 요소 spring<br>**anime.js v4** — stagger 등장·SVG 선 그리기·숫자 카운트업 |
| 상태 | Zustand v5 + IndexedDB 영속화(`idb`) |
| 데이터 파이프라인 | Python + PyMuPDF + Pillow (기출 PDF → 문항 이미지·정답) |
| 배포 | 정적 익스포트 → Cloudflare Workers / Pages |

서버 로직·API 라우트·데이터베이스가 없습니다. 학습 기록은 전부 브라우저의
IndexedDB에 저장되므로 오프라인에서도 동작하며, 서버로 전송되는 개인 데이터가 없습니다.

```
│   ├── eras.ts               # 12개 시대 메타 (컬러·아이콘·분위기)

│   ├── infographics.ts       # 전용 인포그래픽 큐레이션
│   ├── mock-exams/           # 기출 10회차 (임포터가 생성)
│   └── past-exams.ts         # 개념별 기출 출제 이력 (선택)
├── lib/
│   ├── types.ts              # 도메인 타입 계약
│   ├── quiz.ts               # 퀴즈 생성 엔진 (난이도 프로필 포함)
│   ├── srs.ts                # 망각곡선 복습 엔진
│   ├── store.ts              # Zustand 스토어
│   └── utils.ts              # D-Day·등급·레벨 등 유틸
scripts/
├── import-exam.py            # 기출 PDF → 문항 이미지 + 정답
└── match-concepts.py         # 기출 문항 → 개념 자동 연결
public/exams/                 # 기출 시험지 이미지 (WebP, 40MB)
```

### 데이터 모델

모든 개념은 `HistoryEvent` 스키마를 따릅니다.

```ts
{
  id, era, king?, year, yearDisplay, title,
  summary10s, summary30s, summary1m,   // 다단계 요약
  examPoint, significance,             // 출제 포인트 · 역사적 의미
  importance, examFrequency, mustMemorize,
  keywords,
  memory: { story, analogy, mnemonic, wordplay?, emotion?, visual? },
  traps: [{ concept, difference }],    // 실수 방지 비교
  relatedFigures, relatedHeritage,
  prevEventId?, nextEventId?,          // 흐름 모드 체인
  infographics?,                       // 전용 시각 자료
}
```

개념을 추가하려면 해당 시대 파일에 객체 하나를 넣으면 됩니다.
요약·퀴즈·인포그래픽·복습이 모두 이 한 벌의 데이터에서 파생되므로 추가 작업이 없습니다.

## 알려진 한계

- **개념별 출제 빈도(별점)는 추정치입니다.** 한능검 심화의 알려진 출제 경향에 근거한
  값이며, 회차별 기출을 집계한 실측이 아닙니다. 앱에서도 이 구분을 숨기지 않고
  "추정 · 최근 20회 중 N회"로 표시합니다.
  `src/data/past-exams.ts` 에 회차·문항 번호를 채우면 해당 개념의 빈도가
  자동으로 **실측값**으로 전환됩니다(`frequencyOf()`).

- **기출 문항의 개념 연결은 77/500(15%)입니다.** 표본 검토 기준 정확도는 약 97%로,
  연결된 문항은 거의 틀리지 않지만 연결되지 않은 문항이 많습니다.
  매처는 고유명사·연도·시대 단서가 서로 뒷받침될 때만 연결하고, 근거가 하나뿐이면
  비워 둡니다 — 틀린 연결은 없는 것보다 나쁘기 때문입니다.
  텍스트 레이어가 있는 6개 회차만 자동 매칭이 가능하며, 스캔 회차 4개(200문항)는
  대상에서 빠집니다. 결과 화면에도 "자동으로 찾아낸 개념"임을 밝힙니다.

- **문화재 사진과 지도가 없습니다.** 개념 학습의 시각 자료는 SVG 인포그래픽뿐입니다.
  영토 변화 지도, 유물 사진, 왕 계보도는 아직 없습니다.

- 개념 108개는 한능검 핵심 범위를 다루지만 전 범위를 망라하지는 않습니다.
  기출을 풀다 보면 앱에 없는 주제가 나올 수 있습니다.
