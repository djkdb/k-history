# 한국사 레전드 마스터

> **"한국사를 외우는 것이 아니라 평생 기억하게 만든다."**

한국사능력검정시험 전용 **장기기억 강화 학습 시스템**.
노베이스도 시험장에서 자동으로 답이 떠오르게 만드는 것이 목표입니다.

핵심 개념 108개를 12개 시대로 나누어, 하나하나에 **다단계 요약 · 출제 포인트 · 스토리텔링 ·
현대 비유 · 두문자 암기 · 실수 방지 비교표 · 애니메이션 인포그래픽**을 붙였습니다.
학습한 개념은 에빙하우스 망각곡선에 따라 자동으로 복습 일정이 잡히고,
데이터에서 생성된 퀴즈로 인출 연습을 반복합니다.

```bash
npm install
npm run dev      # http://localhost:3000
```

---

## 무엇이 다른가

**1. 글로만 외우지 않습니다**

구조가 있는 정보는 그림으로 봅니다. 신분 구조는 피라미드로, 통치 기구는 조직도로,
사건의 인과는 화살표가 그려지는 흐름도로 나타납니다. 스크롤해서 화면에 들어오면
애니메이션이 재생되고, 우측 상단 버튼으로 다시 볼 수 있습니다.

**2. 아직 안 배운 내용은 묻지 않습니다**

퀴즈 유형을 두 부류로 나눕니다. OX·객관식·빈칸·왕·연도·사건 판별은 **정답 개념 하나만**
알면 풀리므로 오답 보기가 범위 밖이어도 안전합니다. 반면 순서 배열은 **보기 전부**를
알아야 풀리므로, 학습 완료한 개념 안에서만 출제하고 학습량이 3개 미만이면 아예 내지
않습니다. 전 개념 × 전 유형 시뮬레이션으로 범위 밖 출제 0건을 검증했습니다.

**3. 중요도에 근거가 있습니다**

`examFrequency`는 "최근 20회 중 출제된 횟수"를 뜻하고, 별점은 여기서 파생됩니다.
개념 상세에 "최근 20회 중 13회 · 거의 매회 출제"처럼 근거가 함께 표시됩니다.

| 등급 | 기준 | 라벨 | 개수 |
| --- | --- | --- | --- |
| ★★★★★ | 14회 이상 | 반드시 암기 | 20 |
| ★★★★☆ | 9~13회 | 매우 중요 | 38 |
| ★★★☆☆ | 5~8회 | 자주 출제 | 38 |
| ★★☆☆☆ | 3~4회 | 알아두기 | 9 |
| ★☆☆☆☆ | 2회 이하 | 참고 | 3 |

시대별 비중도 한능검 심화 실제 배점에 맞췄습니다 — 조선 16% · 고려 14% · 삼국 11% ·
근현대 33% · 가야 1%.

## 기억 강화 시스템

개념 상세(`/event/[id]`)는 이 앱의 심장입니다. 하나의 개념을 8가지 경로로 기억에 밀어 넣습니다.

**레전드 요약** — 10초 / 30초 / 1분 / 시험 직전 요약을 탭으로 전환합니다.
시험장에서 떠올릴 순서(연도 → 왕 → 사건 → 키워드 → 함정)도 함께 보여줍니다.

**한눈에 보기** — 애니메이션 인포그래픽. 아래 6종 중 개념에 맞는 것이 붙습니다.

| 종류 | 쓰임 | 애니메이션 |
| --- | --- | --- |
| `timeline` | 연표, 제도 변천, 사건 순서 | 시간축이 그려지고 노드가 순차 등장 |
| `pyramid` | 신분 구조 등 위계 | 아래(다수)에서 위(소수)로 쌓임 |
| `orgchart` | 중앙 정치 기구, 행정 조직 | 연결선이 그려진 뒤 기구가 등장 |
| `compare` | 헷갈리는 두 개념 | 좌우에서 마주 보며 진입, 가운데 VS |
| `flow` | 인과 연쇄, 전개 과정 | 단계마다 화살표가 그려짐 |
| `stat` | 규모 수치 | 0에서 목표값까지 카운트업 |

핵심 개념 22개에 전용 인포그래픽 26종을 큐레이션했고(조선 신분 구조, 신문왕 통치 조직,
4대 사화 순서, 전시과 변천, 거란 3차 침입, 임진왜란 전개, 식민 통치 3단계, 6월 항쟁 등),
전용 자료가 없는 개념도 데이터에서 "시대 흐름 속 이 사건의 자리" 연표와
"가장 많이 헷갈리는 지점" 비교를 자동 생성합니다. **108개 전 개념이 최소 1개 이상**의
시각 자료를 갖습니다.

**기억 보조 6종** — 스토리텔링(인물을 드라마 캐릭터처럼) · 현대 비유 · 두문자 암기 ·
말장난 · 감정 연결 · 장면 상상.

**실수 방지** — 시험에서 헷갈리는 지점(`traps`)을 빨간 비교 카드로. 이 데이터는
사건 판별 퀴즈의 해설로도 재사용됩니다.

## 퀴즈 엔진

문제는 미리 작성된 것이 아니라 `HistoryEvent` 필드에서 **생성**됩니다.
데이터를 추가하면 문제도 함께 늘어납니다.

| 유형 | 문제 | 오답 보기 출처 |
| --- | --- | --- |
| `ox` | 요약문의 참·거짓 | 인접 개념의 왕/연도를 바꿔치기 |
| `multiple` | 설명 보고 사건 고르기 | 같은 시대·인접 연도 개념 |
| `king` | 사건 당시의 집권자 | 인접 시기 왕들 |
| `year` | 사건 시기 | 연도가 가까운 사건들 |
| `blank` | 요약문 빈칸 | 인접 개념의 키워드 |
| `order` | 시간순 배열 | **학습 완료 범위 안에서만** |
| `event` | 옳은 설명 고르기 | 같은 시대 다른 사건의 요약문 |

오답 후보는 항상 **같은 시대·인접 연도**로 좁힙니다. 전체에서 무작위로 뽑으면
"시대만 알면 찍히는" 문제가 되기 때문입니다.

**오답 분석** — 세션이 끝나면 시대별·유형별로 집계해 약점을 진단하고,
틀린 개념을 오답노트와 복습 큐에 자동 반영합니다.

## 망각곡선 복습

학습을 완료하면 복습 카드가 생성되고, 아래 간격으로 자동 스케줄링됩니다.

```
당일 → 1일 → 3일 → 7일 → 14일 → 30일
```

정답이면 다음 단계로, 오답이면 한 단계 후퇴하고 12시간 뒤 재등장합니다.
대시보드의 **암기율**은 각 카드의 기억 보존율 `R = exp(-경과일 / 안정도)`을
평균 낸 추정치입니다(안정도 = 현재 단계 간격 + 1).


### 데이터 모델

모든 개념은 `HistoryEvent` 스키마를 따릅니다.

```ts
{
  id, era, king?, year, yearDisplay, title,
  summary10s, summary30s, summary1m,   // 다단계 요약
  examPoint, significance,             // 출제 포인트 · 역사적 의미
  importance, examFrequency, mustMemorize,
  keywords,
  memory: { story, analogy, mnemonic, wordplay?, emotion?, visual? },
  traps: [{ concept, difference }],    // 실수 방지 비교
  relatedFigures, relatedHeritage,
  prevEventId?, nextEventId?,          // 흐름 모드 체인
  infographics?,                       // 전용 시각 자료
}
```

개념을 추가하려면 해당 시대 파일에 객체 하나를 넣으면 됩니다.
요약·퀴즈·인포그래픽·복습이 모두 이 한 벌의 데이터에서 파생되므로 추가 작업이 없습니다.

## 배포

`output: "export"`로 완전 정적 빌드됩니다. `npm run build` 한 번에 `out/`으로
130개 페이지(개념 108 + 시대 12 + 기능 화면 9 + 404)가 프리렌더됩니다.

### Workers (`wrangler`)

`wrangler.jsonc`가 `out/`을 정적 자산으로 서빙하도록 설정돼 있습니다.

```bash
npx wrangler login
npm run preview   # Cloudflare 런타임으로 로컬 미리보기
npm run deploy    # 빌드 + 배포
```

### Pages (Git 연동 자동 배포)

Cloudflare 대시보드 → **Workers & Pages → Create → Pages → Connect to Git**

| 항목 | 값 |
| --- | --- |
| Framework preset | `Next.js (Static HTML Export)` |
| Build command | `npm run build` |
| Build output directory | `out` |
| 환경변수 | `NODE_VERSION=20` |

### 직접 업로드

```bash
npm run build
npx wrangler pages deploy out --project-name=korea-history-legend-master
```

> 서버 렌더링이나 API 라우트가 필요해지면 정적 익스포트로는 처리할 수 없습니다.
> `next.config.ts`의 `output: "export"`를 제거하고
> [`@opennextjs/cloudflare`](https://opennext.js.org/cloudflare) 어댑터로 전환하세요.

## 알려진 한계

- **출제 빈도는 추정치입니다.** 한능검 심화의 알려진 출제 경향을 근거로 판정한 값이며,
  회차별 기출을 집계한 실측 데이터가 아닙니다. 기출 데이터를 확보하면
  `src/data/events/*.ts`의 `examFrequency`를 실측값으로 교체하는 것이 가장 정확합니다.
- **문화재 사진과 지도가 없습니다.** 현재 시각 자료는 SVG 인포그래픽뿐입니다.
  영토 변화 지도, 유물 사진, 왕 계보도는 아직 없습니다.
- 개념 108개는 한능검 핵심 범위를 다루지만 전 범위를 망라하지는 않습니다.
